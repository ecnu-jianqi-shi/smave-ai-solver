# 项目定义与边界

## 项目目标

SMAVE 是一个面向重复数值问题的可验证异构求解器研究项目。项目研究经典直接法、
迭代法、学习型候选、corrector、原方程验收与候选拒绝后的数值续接如何协同，在
满足同一数值正确性合同的前提下，降低完整求解路径成本。

项目范围由求解器科学问题决定。Modelica、Simulink、FMI、PDEBench 和 SuiteSparse
只作为方程来源、兼容入口或实验 workload；只有当它们引出新的求解器机制、数值
困难或可证伪实验时，才进入当前研究主线。

## 核心研究对象

```text
equation/request features
  → eligible numerical actions
  → cost/pass/uncertainty prediction
  → exact bounded solve-plan optimization
  → candidate and corrector
  → original-equation numerical acceptance
  → next numerical path or terminal classical solver
```

其中：

- `gate` 只表示由原方程 residual、约束、一致性条件、分支条件或离散缺陷定义的
  数值验收；
- 候选被拒绝后，从未污染的原请求状态执行下一条数值路径，统一称为“数值续接”；
- 历史代码和指标中的 `fallback` 字段仍可保留，但论文与新文档不把它解释为服务
  故障切换；
- 完整成本包括候选、数据转换或搬运、校正、验收、失败尝试和全部后续数值路径。

## 核心科学问题

1. 如何在 action 通过概率、成本和交互存在不确定性时联合选择 expert、预算与顺序？
2. 如何让学习型候选、corrector 和原方程验收形成数值正确且成本可控的闭环？
3. 如何在 family、conditioning、规模、右端项和硬件偏移下控制错误路由与尾部成本？
4. 如何把线程、批处理和 CPU/GPU/NPU placement 转化为完整路径而非局部 kernel 收益？
5. 如何用冻结数据、强固定基线、负结果和完整失败统计证明方法收益可复现？

## 输入与研究产物

| 类别 | 内容 |
|---|---|
| 输入 | 方程 IR、稀疏矩阵、算子、ODE/DAE/PDE 离散问题、请求特征与容差 |
| 求解动作 | 经典直接/迭代法、学习型候选、预条件器、corrector、预算配置 |
| 方法产物 | Router、完整成本模型、校准与不确定性模型、exact solve-plan optimizer |
| 数值证据 | residual/constraint/gate 结果、失败与数值续接、误差和覆盖率 |
| 性能证据 | 完整路径时间、regret、区间、尾部误差、顺序与交互敏感性 |
| 复现产物 | 数据锁、首次未见运行、机器报告、claim ledger、artifact manifest |

## 纳入范围

- 求解器算法、专家融合、预算选择和执行顺序优化；
- 原方程数值验收、状态无污染续接和数值正确性；
- tail-aware、support-aware、family-aware 和 interaction-aware 路由；
- learned preconditioner、learned multigrid、operator 与经典算法的可验证组合；
- 求解器内部线程并行、批处理和异构 placement；
- 同一数值合同下的外部强基线、消融、负结果和可复现实验。

## 范围判断原则

任何新增任务都必须直接回答至少一个核心科学问题，并产生求解器机制、数值正确性、
完整路径成本或可复现实验证据上的增量。仅扩大平台能力、接口覆盖或工程设施，而不解决
新的求解器难点，不进入论文贡献、审稿条件、阶段验收或方法开发 backlog。

本文所说的“独立矩阵覆盖”或“独立样本”只描述实验划分与统计单位：matrix ID、
collection group、方程实例或满足统计假设的重复试验彼此不泄漏。它不是运行架构要求。

## 当前成功判据

当前阶段的进展只按以下问题判断：

1. 新路由方法是否在未见公开 workload 上稳定竞争或超过强固定求解器策略；
2. p95/max 成本预测误差、通过率不确定性和支持域外推是否得到实质改善；
3. action 交互与顺序敏感性是否被验证为不影响竞争计划，或被方法显式建模；
4. 所有成功结果是否继续通过同一原方程数值合同；
5. 完整路径成本、失败、数值续接、负结果和适用边界是否完整报告。
