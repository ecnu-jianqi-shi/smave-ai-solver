# 风险登记册

本登记册只跟踪会影响求解器创新、数值正确性、完整路径性能或论文证据的风险。
部署基础设施问题不属于当前研究风险。

| 风险 | 影响 | 早期信号 | 缓解措施 |
|---|---|---|---|
| 完整成本建模不完整 | 局部加速被校正、验收或续接成本抵消 | kernel 快但完整路径回归 | 逐 action 计入转换、候选、corrector、gate 与全部续接 |
| 成本预测尾部过大 | 少数灾难性误路由主导 regret | p95/max 远高于 median | 单侧校准上界、support penalty、稳健基线 abstention |
| 通过率校准失真 | Router 高估失败 action | Brier/ECE 高或 held-out 通过率塌陷 | 独立 calibration、有限样本上界、分 family 可靠性分析 |
| 支持域外推 | 未见矩阵被错误映射到训练 action | feature 超出训练支持区间 | action-specific support bounds、外推距离与 anchor 续接 |
| family anchor 不稳定 | 训练时最优固定策略随计时噪声漂移 | 多折 anchor 频繁变化 | 多折 group-disjoint 验证、相对收益门槛、报告 anchor 漂移 |
| action 交互破坏独立模型 | 点估计最优顺序在真实执行中变差 | interaction/order delta 改变竞争排名 | 交互实验、条件成本模型或显式 interaction-aware optimizer |
| 小样本选择偏差 | 开发折收益不能迁移到新冻结数据 | 某一折显著领先、其余折回归 | collection-group-disjoint 交叉验证后再冻结唯一未见集合 |
| 强固定基线被低估 | 自适应方法结论虚高 | fixed SuperLU/family-fixed 更优 | 把强固定策略列为主要基线并对称计费 |
| 原方程验收实现缺陷 | 错误候选被接受 | gate mismatch 或高精度复算失败 | 独立 residual 实现、负向注入、高精度抽查和逐路径日志 |
| 候选状态污染续接 | 后续经典路径不再等价于原请求 | 候选拒绝后重跑结果变化 | attempt-local state、原状态恢复和状态污染单元测试 |
| corrector 预算选择错误 | 校正过少失败、过多吞噬收益 | 接受率和完整成本随预算非预期变化 | expert--budget 联合 action、预算消融和 exact DP 对照 |
| 顺序或缓存污染计时 | 假收益来自热状态或执行顺序 | AB/BA、轮换或冷启动差异大 | 配对交替、顺序敏感性、独立进程与完整 setup 计费 |
| 数值家族覆盖不足 | 方法只在少数矩阵形态成立 | family-balanced held-out 回归 | 扩充公开 workload、按 family 报告覆盖率与负结果 |
| 外部基线不足 | 创新性和意义无法定位 | 只优于仓库内部静态策略 | 增加强 hybrid learned-solver、预条件器和算法选择基线 |
| 证据冻结被覆盖或泄漏 | 未见结果失去可信度 | split/hash 改变或首次目录被重跑 | append-only 首次运行、数据锁、manifest 与 lineage 检查 |
| 论文超出真实证据 | 审稿结论不可复核 | 摘要主张强于主表或隐藏负结果 | claim--evidence ledger、机器生成数字和严格复审 |
