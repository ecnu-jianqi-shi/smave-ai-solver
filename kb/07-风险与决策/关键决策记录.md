# 关键决策记录

## ADR-001：以 FMI 作为首版统一边界（已被 ADR-006 替代）

- **状态：** 已替代
- **原因：** Modelica 与 Simulink 内部表示差异大；FMI 已提供跨工具执行契约。
- **后果：** 原生 `.mo/.slx` 转换留给适配器；部分内部状态可能不可见。

## ADR-002：等价限定为声明运行域内的行为等价

- **状态：** 接受
- **原因：** 有限数据无法证明任意输入下全局严格等价，混合事件系统尤其如此。
- **后果：** 每个模型必须携带运行域、验证报告与 OOD 策略。

## ADR-003：先 Python MVP，再研究 Julia 可微 FMU（已被 ADR-012 替代）

- **状态：** 已替代
- **原因：** Python 更适合快速完成端到端产品闭环；FMIFlux/Julia 对 NeuralFMU 研究有独特价值。
- **后果：** 数据与模型契约必须跨语言，避免框架锁定。

## ADR-004：训练目标不能替代原方程验收

- **状态：** 接受
- **原因：** 防止训练 loss、Router confidence 或 surrogate error 替代原方程 residual、约束和离散缺陷。
- **后果：** 所有成功返回路径执行同一数值验收合同，训练框架不能自行判定结果可接受。

## ADR-005：首版不以大模型直接生成代理权重

- **状态：** 接受
- **原因：** 数值动力学需要轨迹证据与可重复验证；LLM 更适合配置、变量语义和实验建议。
- **后果：** AI 核心先采用系统辨识、科学机器学习和降阶模型。

## ADR-006：源方程 IR 取代 FMI 成为核心边界

- **状态：** 接受，替代 ADR-001 的“首版统一边界”部分
- **原因：** FMU 隐藏方程结构，无法为 AI 候选解提供快速方程级验证，并会把数据准备推向不可行的输入枚举。
- **后果：** 优先接入 OpenModelica 编译器 IR 和 Simulink 块语义；FMI 仅保留为兼容、部署和低等级差分测试。

## ADR-007：AI 首先作为 block solver 加速器

- **状态：** 接受
- **原因：** 方程块候选解可以直接以原 residual 验证，并在失败时局部调用原数值求解器。
- **后果：** 第一阶段衡量数值续接率、求解器迭代和墙钟收益，而不是全轨迹 MSE。

## ADR-008：采用反例引导而非输入枚举

- **状态：** 接受
- **原因：** 输入是函数空间，参数组合连续，网格枚举既不可完成也不能证明正确。
- **后果：** 以求解器访问分布为 seed，通过 residual 优化、区间细分和闭环 adversarial search 补充数据。

## ADR-012：项目自有实现统一使用 C++20

- **状态：** 接受，替代 ADR-003 的实现语言决策
- **原因：** 编译前端、训练控制、原方程验收器与求解 runtime 需要共享类型、容差和数值合同，避免多语言路径产生不一致结果。
- **后果：** 项目源码、CLI、测试和离线工具统一使用 C++20 + CMake/CTest；第三方 Tensor 模型仅通过 ONNX Runtime、TensorRT 等稳定 C/C++ API 或不可变 artifact 接入。

## ADR-009：借鉴 PINN 训练机制，不采用完整模型替代

- **状态：** 接受
- **原因：** 原方程 residual 可提供大量无标签训练信号、物理约束和反例搜索目标，但纯 PINN 难以可靠处理刚性、高指数 DAE、事件与多根问题。
- **后果：** 对方程块采用少量求解器标签 + residual + 约束 + 分支损失；运行时仍由原方程 residual gate 验收并保留 block 数值续接。

## ADR-010：以统一技术栈综合吸收研究成果

- **状态：** 接受
- **原因：** foundation model、PINN、神经预条件器、learned multigrid 和神经算子解决不同层次的问题，简单并列会造成重复数据管线、冲突验证和不可维护的专家集合。
- **后果：** 所有成果必须映射到统一方程 IR、Expert ABI、两级 Router、runtime gate 和专家生命周期；允许组合专家，但不允许绕过原方程验证。

## ADR-011：候选角色按数值证据约束

- **状态：** 接受
- **原因：** 论文精度、硬件和加速口径差异很大，不能因公开加速比直接返回候选结果。
- **后果：** 新专家按 Research、Candidate-only、Warm-start、Corrected、Direct 角色评测；失败时继续下一条数值求解路径。
