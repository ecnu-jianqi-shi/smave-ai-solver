# 反例引导训练与采样

## 为什么不枚举输入

参数、初值和输入函数形成连续且高维的组合空间，有限网格无法覆盖。项目不应尝试证明“训练集覆盖所有输入”，而应让原方程定义可检查目标，并把采样集中到求解器实际访问和验证器发现困难的区域。

## 两层空间

### 外层：场景空间

只描述应用允许的参数、初值、控制器和扰动族，用于声明适用域和产生代表性轨迹。可使用 Sobol/LHS，但它只是初始探索，不是正确性证明。

### 内层：方程块上下文空间

AI block solver 的输入不是完整输入历史，而是求解时刻的局部上下文 $c_b$：上游变量、参数、时间、前一收敛解、步长和模式。原求解器运行自然地产生这些样本，维度通常远小于端到端函数空间。

## CEGIS 风格闭环

1. **Seed：** 用少量典型工况运行原求解器，采集 block 调用上下文与收敛解；
2. **Learn：** 训练候选解、warm-start 或 preconditioner 模型；
3. **Verify：** 对候选点计算精确 residual、约束和局部收敛指标；
4. **Search：** 最大化 residual/fallback 概率，寻找反例；
5. **Refine：** 原求解器求出反例真解并加入缓存；
6. **Stop：** 验证预算内找不到新反例，且 fallback 率和性能达标。

## 反例搜索方法

- 对可微 residual 直接做 projected gradient ascent；
- 对不可微/事件模式用 CMA-ES、贝叶斯优化或交叉熵方法；
- 对低维区间使用 branch-and-bound/interval arithmetic；
- 在轨迹层用 adversarial MPC 搜索会驱动系统进入高 residual 区域的输入；
- 对事件边界和多根分岔面进行定向采样；
- 用 ensemble disagreement 作为候选指标，但最终仍以原 residual 为准。

## 不依赖“真值标签”的训练

由于原方程可见，可以直接最小化

$$L_{eq}=\mathbb E_{c_b}\|W_bR_b(N_\theta(c_b);c_b)\|^2,$$

并辅以少量原求解器收敛解监督。这减少标签生成，但必须防止收敛到错误根；可加入前一时刻连续性、分支 ID、能量和稳定性约束。

具体采用 [[03-原理/PINN可借鉴机制]] 中的混合目标，而不是纯 PINN：初始 seed 和高风险区域保留求解器标签；普通配点使用 residual；多根、事件和近奇异区域增加分支/Jacobian 约束。

## Residual-Based Adaptive Refinement

每轮在未标注候选池上计算训练残差，并追加：

1. 每个方程 residual 最大的点，避免总范数掩盖弱方程；
2. fallback 周围的局部扰动点；
3. Jacobian 条件数高或根分支接近的点；
4. 事件前后但不跨模式混合的点；
5. 已验证 cell 与未验证 cell 的边界点。

配点预算按 residual 尾部分布分配，不按参数笛卡尔积平均分配。连续多轮没有新反例时，才能冻结该域的训练集。

## 课程式目标

1. 先学习原求解器 warm start，风险最低；
2. 再允许 residual 达标时跳过迭代；
3. 对经区间/形式验证的子域启用直接接受；
4. 始终保留 block solver fallback；
5. 当 fallback 率长期较高时，拆分域或模型，而不是扩大一个黑盒网络。

## 应报告的指标

- block residual 的 P50/P99/max；
- AI 直接接受率与 fallback 率；
- Newton/Krylov 迭代减少量；
- 错根/分支跳转次数；
- 事件附近 fallback 率；
- 反例发现曲线和未覆盖单元；
- 端到端墙钟加速，而非只看网络推理时间。
