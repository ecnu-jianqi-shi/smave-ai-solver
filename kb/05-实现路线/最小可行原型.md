# 最小可行原型

## 推荐基准

1. **RC 热模型**：稳定线性/轻微非线性，验证整条管线；
2. **Van der Pol 或非线性摆**：周期、相位误差和长时滚动；
3. **带恒温器的房间**：事件与 hysteresis；
4. 后续加入 Modelica Standard Library 中的机械/流体小模型。

## MVP 配置示意

```yaml
model:
  fmu: artifacts/model.fmu
  kind: model_exchange
domain:
  parameters:
    mass: {min: 0.8, max: 1.2}
  initial_conditions:
    angle: {min: -0.5, max: 0.5}
  inputs:
    torque:
      generator: prbs
      min: -1.0
      max: 1.0
simulation:
  start_time: 0.0
  stop_time: 20.0
  output_interval: 0.01
dataset:
  train_scenarios: 500
  validation_scenarios: 100
  test_scenarios: 200
acceptance:
  nrmse_max: 0.03
  constraint_violation_rate_max: 0.001
  speedup_min: 20
```

## CLI 草案

```text
smave inspect model.fmu
smave sample experiment.yaml
smave simulate experiment.yaml
smave train experiment.yaml --model residual-mlp
smave validate run-id
smave export run-id --format onnx
```

## Definition of Done

- 所有数据带 FMU hash、配置、随机种子和工具版本；
- 时间序列按场景切分；
- 至少包含线性、简单非线性和可解释基线；
- 验证集不参与模型/超参最终选择；
- 报告逐输出误差、最坏工况、长时稳定性和端到端加速比；
- 模型包携带有效运行域和失败回退策略；
- 一条命令可复现实验。
