# 验证协议

## 数据切分

- Train：拟合参数；
- Validation：超参和早停；
- Test-ID：运行域内未见完整工况；
- Test-boundary：参数与初值边界；
- Test-OOD：超出声明域，用于拒绝检测，不用于证明等价；
- Stress：长时、强扰动、闭环和事件密集场景。

所有切分按 `trajectory_id`，参数组合、输入种子和初值不得跨集合泄漏。

## 指标

| 类别 | 指标 |
|---|---|
| 点误差 | MAE、RMSE、NRMSE、最大绝对误差 |
| 轨迹形状 | DTW、相关性、相位误差 |
| 任务特征 | 峰值、稳态值、超调、上升/稳定时间、积分量 |
| 动力学 | 一步误差、多时域 rollout、频率响应 |
| 事件 | precision/recall、事件次序、时刻误差、reset 后状态误差 |
| 物理 | 守恒残差、边界/非负性、代数约束残差 |
| 鲁棒性 | 最坏分位数、长时发散率、扰动敏感性 |
| 性能 | 单轨迹、批量吞吐、初始化开销、内存、端到端 speedup |

## 统计报告

- 不只给平均值：报告 median、P90、P99 和 worst case；
- 对每个输出、每类工况分别报告；
- 采用 bootstrap 置信区间；
- 配对求解器比较应对同一场景、同一重复的完整端到端墙钟比做 bootstrap；固定并记录随机种子与重采样次数，稳定加速门禁要求 `95%` 区间下界大于 1；
- 将失败轨迹和参数保存为可重放案例；
- 同硬件、同输出采样点对比原模型；
- 同时报告训练/数据生成成本和 break-even 调用次数。

## 发布门禁

```text
G1 数据覆盖通过
G2 ID 精度通过
G3 边界与压力测试通过
G4 事件/物理约束通过
G5 性能收益通过
G6 OOD 检测与回退通过
```

任何必要门禁失败，模型只能标记为实验产物，不得称为可替代模型。

## PINN/Block Solver 专项指标

- 独立 runtime residual 的 P50、P99 和最大值；
- 每个原方程分别统计通过率，不能只报告聚合 loss；
- 正确根/分支保持率与 branch switching 次数；
- AI warm start 后 Newton/Krylov 迭代分布；
- 直接接受率、fallback 率和错误接受数；
- 事件邻域、近奇异区域和边界 cell 的专项结果；
- training residual 与 runtime residual 的一致性 golden test；
- 训练配点外的 adversarial residual 搜索结果。

训练 PINN loss、训练 collocation residual 或监督误差均不得替代独立 runtime gate 指标。

## Equation-MoE 综合系统指标

| 维度 | 必须报告 |
|---|---|
| Router | Top-1/Top-k 命中、保守误路由、危险误路由、校准误差 |
| 专家组合 | direct、corrected、warm-start、full fallback 各自占比 |
| 线性内层 | setup/apply 时间、Krylov 迭代、最终 residual |
| 非线性外层 | Newton 迭代、分支保持、重初始化和失败率 |
| Tensor | batch 利用率、kernel、传输、队列等待和内存 |
| 持续学习 | 新专家适配时间、break-even、晋级/降级和回滚次数 |
| 安全 | 错误接受数、OOD 拒绝率、fallback 成功率和最坏 QoI 误差 |

综合系统必须与以下对象比较：

1. 原始经典求解计划；
2. 调优后的最佳经典求解器；
3. 每个单独 AI 专家；
4. 固定专家级联；
5. 两级 Router 的 Equation-MoE。

只有 Equation-MoE 在相同精度和硬件条件下优于最佳可用单专家，才能证明“综合利用”产生了系统收益，而不是增加了调度开销。

## 专家晋级门禁

```text
Research  → 论文 benchmark 可复现
Shadow    → 不采用结果时无未解释偏差
WarmStart → 原 solver 收敛率不降低且 P99 有收益
Corrected → 校正后达到原 residual、约束和分支标准
Direct    → 声明域内 QoI 0.01%、Top-k >95%、近零错误接受
```

门禁按方程家族、运行域、容差和硬件分别记录。某专家在 GPU batch 场景达到 Direct，不代表其在 CPU 单实例场景也获得相同权限。

## 防止错误结论

- 与零阶保持、线性状态空间和小型 MLP 比较；
- 不以随机时间点切分后的高分作为泛化证据；
- 不把原求解器低精度输出当作绝对真值；
- 不忽略事件附近和边界工况；
- 不只计算神经网络 kernel 时间而忽略预处理与传输；
- 不在代理训练域之外声称有效。
