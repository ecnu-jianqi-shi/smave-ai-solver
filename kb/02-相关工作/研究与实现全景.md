# 研究与实现全景

## 路线分类

| 路线 | 代表工作 | 能解决什么 | 局限 | 对本项目启示 |
|---|---|---|---|---|
| FMI 互操作 | FMI Standard、FMPy、PyFMI、FMI.jl | 统一执行 Modelica/Simulink 导出的模型 | FMU 能力受导出工具和 FMI 类型影响 | 作为数据生成和集成边界 |
| 混合 FMU + 神经网络 | NeuralFMU、FMIFlux.jl | 将可微 FMU 与神经网络组合，学习未知/昂贵部分 | 方程语义和局部求解结构可能不可见 | 对比研究，不作为核心架构 |
| 方程编译与结构分析 | OpenModelica BackendDAE、ModelingToolkit、CasADi | 保留 residual、Jacobian、BLT/SCC 和求解结构 | 需要编译器级集成 | 核心知识表示与验证基础 |
| 神经动力学 | Neural ODE、Universal Differential Equations | 连续时间建模、非均匀采样、嵌入先验 | 刚性、事件和长时误差困难 | 连续系统基线与混合模型骨架 |
| 稀疏辨识 | SINDy、PySINDy | 从数据发现可解释稀疏动力学 | 噪声、隐藏状态和复杂非线性敏感 | 低维、可解释基线 |
| 降阶模型 | POD/自动编码器/动态模式分解 | 压缩高维状态，再学习低维动力学 | 需要状态快照；跨参数泛化困难 | 高维模型的必要组件 |
| 算子学习 | DeepONet、Fourier Neural Operator | 学习函数到函数映射，适合多输入场 | 数据量大；对低维控制系统未必经济 | PDE/场模型的后续路线 |
| 工业 AI-ROM | MATLAB Reduced Order Modeler、Simulink 相关 ROM 工作流 | 从仿真/实验数据训练并部署 ROM | 工具链封闭，泛化验证依赖用户 | 证明商业需求与可行性已存在 |
| 商业代理建模 | Ansys Twin Builder ROM、Siemens HEEDS/Simcenter ROM 等 | 数字孪生、优化和实时代理 | 通常围绕自家生态，内部算法不透明 | 产品需强调开放 FMI 与可审计验证 |

## 关键研究判断

### 1. 统一方程 IR 比统一可执行格式更重要

Modelica 是方程式、面向对象的声明式语言，Simulink 是块图模型；二者内部语义差异很大。核心 IR 应把两者规范化为 hybrid DAE、离散更新、事件和方程依赖，同时保留 residual 与源映射。FMI 只把它们收敛为执行接口，适合兼容和部署，但不足以支持方程级验证。

### 2. “代理”有多个粒度

- **端到端输出代理**：直接学习 $(u,p,x_0)\mapsto y_{0:T}$，简单但可能忽略状态一致性；
- **一步状态转移**：学习 $x_{k+1}=f_\theta(x_k,u_k,p)$，部署灵活但滚动误差累积；
- **连续向量场**：学习 $\dot x=f_\theta(x,u,p)$，可换积分器但训练成本高；
- **残差/闭合项**：$\dot x=f_{physics}+r_\theta$，通常最数据高效；
- **潜空间模型**：编码高维状态后学习低维动力学，适用于大系统；
- **分层模型组代理**：对子系统分别代理，保留耦合结构和接口约束。

### 3. 事件是主要分水岭

普通神经 ODE 假设平滑向量场，而 Modelica/Simulink 常包含饱和、继电器、状态机、零交叉和离散控制。可行方案是显式拆成：模式分类器、连续模式动力学、事件时间/guard、reset map，并对事件附近过采样。

### 4. 已有实现并未完成“一键通用替换”

现有开源项目解决了 FMI 执行、可微混合或动力学学习的局部问题；商业工具提供特定生态内的 ROM 流程。仍缺少一个面向 Modelica 与 Simulink、开放格式、带自动 DOE 和严格验证报告的端到端通用工具。这正是本项目的潜在差异化空间。

## 成熟度估计

| 能力 | 成熟度 | 说明 |
|---|---:|---|
| FMU 批量执行与变量读写 | 高 | 多语言运行库成熟 |
| 连续低维系统代理 | 中高 | 方法多，工程细节可控 |
| 已知结构 + 学习残差 | 中 | 研究活跃，需处理梯度和稳定性 |
| 高维场的参数化 ROM | 中 | 可用但数据与训练成本高 |
| 复杂事件系统自动代理 | 低 | 需要专门结构和验证 |
| 任意 Modelica/Simulink 一键等价替代 | 很低 | 尚无可信通用实现证据 |
