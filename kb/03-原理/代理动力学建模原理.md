# 代理动力学建模原理

## 问题形式

Modelica 模型经编译后常可表示为 DAE：

$$F(\dot x,x,z,u,p,t)=0,$$

其中 $x$ 是动态状态，$z$ 是代数变量，$u$ 是外部输入，$p$ 是参数。Simulink 模型也可在执行语义上归约为连续状态、离散状态、块输出与事件更新。代理模型不必重建源码，只需在运行域内复现关注量及其动力学关系。

## 三种主要训练目标

### 离散状态转移

$$\hat x_{k+1}=f_\theta(\hat x_k,u_k,p,\Delta t),\qquad \hat y_k=g_\theta(\hat x_k,u_k,p).$$

优点是推理简单、适合固定采样周期；缺点是多步滚动误差和换步长困难。训练应混合 teacher forcing 与 rollout loss。

### 连续时间向量场

$$\dot{\hat x}=f_\theta(\hat x,u,p,t).$$

由数值积分器推进，支持非均匀时间点和连续控制。需要考虑刚性、伴随梯度误差和求解器成本。

### 混合机理—数据模型

$$\dot{\hat x}=f_{known}(\hat x,u,p,t)+r_\theta(\hat x,u,p,t).$$

神经网络只学习残差、闭合项或昂贵子模块。它保留部分结构，往往更少数据、更易解释，并能借助 FMU 作为机理组件。

## 数据生成

训练集覆盖度决定模型上限。数据生成器应联合采样：

- 参数 $p$：Latin hypercube、Sobol、边界点和物理可行约束；
- 初始条件 $x_0$：稳定域、边界域、典型工况；
- 输入 $u(t)$：阶跃、斜坡、PRBS、多正弦、业务控制序列；
- 求解设置：高精度参考容差、固定输出网格、事件日志；
- 主动学习：优先补采代理不确定性高或误差大的区域。

数据切分必须按**完整工况/轨迹**进行，不能随机打散时间点，否则会产生严重泄漏。

## 损失设计

建议组合：

$$L=\lambda_1L_{rollout}+\lambda_2L_{derivative}+\lambda_3L_{features}+\lambda_4L_{physics}+\lambda_5L_{event}.$$

- $L_{rollout}$：多步轨迹误差；
- $L_{derivative}$：局部向量场或一步误差；
- $L_{features}$：峰值、稳态、能量、频域特征；
- $L_{physics}$：守恒、边界、代数约束；
- $L_{event}$：事件类型、时刻、重置后状态误差。

## 稳定性机制

- 状态与参数无量纲化；
- 谱归一化、Lipschitz 约束或稳定参数化；
- 多时域 rollout curriculum；
- 对耗散系统加入能量单调性约束；
- 部署时进行分布外检测，超域回退到原 FMU；
- 对闭环系统在控制器联调环境中验证，而非只看开环 MSE。

## 事件系统

将混合动力系统显式表示为：

1. 模式 $q$；
2. 每个模式的连续动力学 $f_{\theta,q}$；
3. guard/事件函数 $h_{q\to q'}(x,u,p)$；
4. reset map $R_{q\to q'}(x)$。

训练数据需要保存事件前后状态和事件标识。验证时单独报告漏检、误检、次序和事件时刻误差。
