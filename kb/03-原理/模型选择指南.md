# 模型选择指南

| 问题特征 | 首选模型 | 基线/备选 | 不宜首选 |
|---|---|---|---|
| 低维、固定步长、连续系统 | residual MLP/GRU 状态转移 | SINDy、Neural ODE | 大型 Transformer |
| 非均匀采样或需换积分器 | Neural ODE/UDE | latent ODE | 纯序列到序列输出 |
| 有可信机理，只缺未知项 | residual/UDE/NeuralFMU | Gaussian process residual | 全黑盒端到端 |
| 高维状态、低维流形 | autoencoder + latent dynamics | POD + regression | 原空间巨型 MLP |
| PDE/空间场，多边界函数 | DeepONet/FNO | POD-ROM | 普通 RNN |
| 明显离散模式/事件 | hybrid mode model | 分模式树模型 | 单一平滑 Neural ODE |
| 需要强可解释性 | SINDy/符号回归 | 小型物理约束网络 | 深层黑盒网络 |
| 小数据且需不确定性 | Gaussian process/state-space | ensemble | 过参数化深网 |

## 默认基线组合

每个基准至少比较：

1. **原求解器**：准确度与耗时基准；
2. **零阶/线性 ROM**：判断深度模型是否真正必要；
3. **residual MLP 一步模型**：工程上简单且常具竞争力；
4. **Neural ODE 或 UDE**：连续时间路线；
5. **SINDy**：低维可解释路线。

只有当序列长度、长依赖或多模态输入证明确有必要时再加入 Transformer 类模型。

## 模型组策略

- 小规模强耦合：整体代理，减少接口误差；
- 大规模弱耦合：按 FMU/子系统代理，保留系统拓扑；
- 快慢多尺度：慢子系统代理 + 快子系统机理求解，或多速率模型；
- 安全关键子系统：保留机理模型，AI 仅用于非关键昂贵部分；
- 代理接口必须声明采样周期、状态性、初始化与可接受输入域。
